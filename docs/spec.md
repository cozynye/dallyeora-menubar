# 달려라 메뉴바 — 설계 스펙

작성일: 2026-11-05
시안: https://claude.ai/artifact/93aJQDTi8XMQqFMYqJFFbY

## 1. 목적

CPU 사용률에 따라 메뉴 막대 캐릭터의 움직임 속도와 문구가 바뀌는 macOS 앱을, 한국 밈 캐릭터와 문구로 만든다.
GitHub에 공개하고 Releases로 `.app`을 배포한다.

## 2. 범위

### v1에 포함
- 캐릭터 4종: **개복치(기본값)**, 퇴근하는 김대리, 삼겹살 불판, 배달 라이더
- 드롭다운 메뉴에서 캐릭터 전환. 선택은 앱을 다시 실행해도 유지된다.
- 말투 전환: 표준어 / 경상도. 선택은 유지된다.
- 메뉴 막대 표시: 단색 아이콘 + 현재 단계 문구
- 드롭다운 맨 위: 캐릭터 이름과 CPU 사용률(%)

### v1에서 제외
- 문구 숨기기, 로그인 시 자동 실행, 설정 창, 메모리/네트워크 등 CPU 외 지표, 공증(notarization)

## 3. 동작

### 3.1 CPU 측정
- 2초마다 `host_statistics(HOST_CPU_LOAD_INFO)`로 user/system/idle/nice tick을 읽는다.
- 사용률 = 직전 측정과의 tick 차이로 계산: `(Δuser + Δsystem + Δnice) / Δ전체 × 100`, 0–100으로 제한한다.
- 첫 측정 전이나 Δ전체가 0이면 0%로 본다.

### 3.2 애니메이션 속도
- 프레임 간격 = `0.2 - (cpu / 100) × 0.17`초 (0% → 0.2초, 100% → 0.03초).
- 매 프레임마다 `phase`를 일정량(0.6 rad) 증가시키고 아이콘을 다시 그린다.
- CPU 값이 바뀌면 타이머 간격을 다시 설정한다.

### 3.3 문구 단계
각 캐릭터는 최소 CPU 값 오름차순으로 정렬된 4단계를 가진다. 시작값이 현재 CPU 이하인 단계 중 마지막 단계를 선택한다.

| 캐릭터 | 단계 시작 | 표준어 | 경상도 |
|---|---|---|---|
| 개복치 | 0 | 평온하게 헤엄 중 | 편하게 헤엄치는 중이다 |
| | 25 | 햇빛에 깜짝 놀람 | 깜짝 놀랐다 아이가 |
| | 50 | 스트레스로 위독 | 스트레스 받아 죽겠다 |
| | 90 | 충격으로 사망… 앱 좀 꺼 주세요 | 마 죽었다… 앱 좀 꺼라 |
| 퇴근하는 김대리 | 0 | 월급루팡 중 | 월급 받고 노는 중이데이 |
| | 25 | 일하는 척하는 중 | 일하는 척 하고 있다 아이가 |
| | 50 | 오늘 야근 각 | 오늘 야근이다, 마 |
| | 75 | 칼퇴 질주! | 퇴근한다, 비키라! |
| 삼겹살 불판 | 0 | 불판 달구는 중 | 아직 불도 안 올랐다 |
| | 25 | 지글지글 | 지글지글하네 |
| | 50 | 지금 뒤집어! | 퍼뜩 뒤집으라 |
| | 75 | 탄다 탄다! 노트북 뜨거움 | 다 탔다 아이가 |
| 배달 라이더 | 0 | 조리 중… | 아직 음식 만드는 중이다 |
| | 25 | 픽업 완료 | 음식 받았다 |
| | 50 | 배달 중 | 간다 안 카나 |
| | 75 | 곧 도착합니다! | 다 왔다, 문 열어라 |

### 3.4 캐릭터 그림
- 논리 좌표 28×18pt 캔버스에 Core Graphics로 선/도형을 그린다. 시안 페이지의 그림을 그대로 옮긴다.
- 이미지는 `isTemplate = true`로 설정해 라이트/다크 모드 색을 시스템이 맞추게 한다.
- 캐릭터별 상태 변화:
  - 개복치: 25% 미만 물방울, 50% 이상 떨림 + 땀방울, 90% 이상 180° 뒤집힘 + X 눈
  - 김대리: CPU에 비례해 상체 기울기·다리 폭 증가, 75% 이상 속도선
  - 삼겹살: 연기 개수 = 1 + ⌊cpu/25⌋, 75% 이상 고기 뒤집힘
  - 라이더: 25% 미만 정지 + 김, 25% 이상 바퀴 회전, 75% 이상 속도선

### 3.5 드롭다운 메뉴
```
개복치                 CPU 42%
스트레스로 위독
───────────────
캐릭터          ▸  ✓개복치 / 퇴근하는 김대리 / 삼겹살 불판 / 배달 라이더
말투            ▸  ✓표준어 / 경상도
───────────────
종료                       ⌘Q
```
메뉴가 열려 있는 동안에도 CPU %와 문구가 갱신된다.

## 4. 구조

Swift Package (Swift 6, macOS 14+), AppKit `NSStatusItem` 기반. Dock 아이콘 없음(`LSUIElement`).

| 구성 요소 | 책임 | 의존 |
|---|---|---|
| `CPUUsage` | tick 두 개로 사용률을 계산하는 순수 함수 | 없음 |
| `CPUMonitor` | 2초 타이머로 tick을 읽고 사용률을 콜백으로 전달 | `CPUUsage` |
| `Mascot` 프로토콜 | `id`, `name`, `tiers`, `draw(in:phase:cpu:)`. Swift 기본 타입 `Character`와 이름이 겹치지 않게 Mascot으로 명명 | 없음 |
| `Tier`, `Tone` | 단계 데이터, 말투 enum, 단계 선택 함수 | 없음 |
| `Mascots/*.swift` | 캐릭터 4종 구현 | `Mascot` |
| `AnimationClock` | CPU → 프레임 간격 계산, phase 진행 | 없음 |
| `Settings` | 캐릭터 id·말투를 `UserDefaults`에 저장/로드. 없거나 알 수 없는 값이면 개복치·표준어 | `UserDefaults` |
| `StatusItemController` | 아이콘 렌더링, 문구 갱신, 메뉴 구성 | 위 전부 |

로직(사용률 계산, 단계 선택, 간격 계산, 설정)은 AppKit 없이 테스트할 수 있는 별도 타깃(`DallyeoraCore`)에 둔다.

## 5. 테스트
- `swift test` 단위 테스트: 사용률 계산(정상/Δ0/범위 제한), 단계 경계값(24/25, 89/90 등), 프레임 간격 양 끝값, 설정 기본값과 저장·복원
- 그림은 실제 실행해서 메뉴 막대에서 눈으로 확인한다.

## 6. 빌드·배포
- `scripts/make-app.sh`: `swift build -c release` → `.app` 번들 구성(Info.plist 포함) → ad-hoc 서명 → dmg (앱 + Applications 바로가기)
- GitHub Releases에 dmg를 올린다.
- 공증하지 않으므로 README에 "처음 실행 시 우클릭 → 열기" 안내를 적는다.

## 7. 저작권
캐릭터는 직접 그린 도형만 사용하고, 실존 캐릭터·브랜드 로고·브랜드 색은 쓰지 않는다.
