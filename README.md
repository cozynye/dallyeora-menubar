# 달려라 메뉴바 (Dallyeora)

CPU와 메모리 사용률을 맥 메뉴 막대(메뉴바)에 움직이는 캐릭터로 보여 주는 macOS 앱이다. 기본 캐릭터인 개복치는 평소에는 느긋하게 헤엄치다가 사용률이 오르면 점점 빨리 움직이고, 90%를 넘기면 배를 뒤집고 죽어 버린다. 개복치, 퇴근하는 김대리, 삼겹살 불판, 배달 라이더까지 한국 밈 캐릭터 네 가지가 들어 있고, 메뉴에서 골라 쓸 수 있다.

## 캐릭터

캐릭터마다 CPU 구간에 따라 메뉴 막대에 뜨는 문구가 네 단계로 바뀐다. 표의 숫자는 그 단계가 시작되는 CPU 사용률이다.

| 캐릭터 | 0% | 25% | 50% | 75% (개복치는 90%) |
|---|---|---|---|---|
| 개복치 (기본) | 평온하게 헤엄 중 | 햇빛에 깜짝 놀람 | 스트레스로 위독 | 충격으로 사망… 앱 좀 꺼 주세요 |
| 퇴근하는 김대리 | 월급루팡 중 | 일하는 척하는 중 | 오늘 야근 각 | 칼퇴 질주! |
| 삼겹살 불판 | 불판 달구는 중 | 지글지글 | 지금 뒤집어! | 탄다 탄다! 노트북 뜨거움 |
| 배달 라이더 | 조리 중… | 픽업 완료 | 배달 중 | 곧 도착합니다! |

그림도 단계에 맞춰 달라지는데, 개복치는 놀라면 몸을 떨면서 땀을 흘리다가 마지막에는 뒤집혀 눈이 X가 되고, 김대리는 CPU가 오를수록 몸을 앞으로 숙이고 보폭이 넓어진다. 삼겹살은 연기가 하나씩 늘다가 75%를 넘으면 고기가 뒤집히고, 라이더는 25% 아래에서는 가만히 서서 음식이 나오길 기다리다가 그 위로 올라가면 바퀴를 굴리기 시작한다.

말투는 표준어와 경상도 중에 고를 수 있다. 경상도로 바꾸면 개복치는 "편하게 헤엄치는 중이다"로 시작해서 "마 죽었다… 앱 좀 꺼라"로 끝나고, 김대리는 마지막에 "퇴근한다, 비키라!"를 외친다. 고른 캐릭터와 말투는 앱을 껐다 켜도 그대로 남아 있다.

캐릭터가 반응하는 지표는 메뉴의 "지표"에서 CPU와 메모리 중에 고를 수 있다. 메모리 사용률은 앱 메모리, 와이어드 메모리, 압축된 메모리를 더해 전체 메모리로 나눈 값인데, macOS는 남는 메모리를 캐시로 적극 활용하기 때문에 평소에도 70~80%를 넘는 경우가 많고, 그래서 메모리 모드에서는 캐릭터가 높은 단계에 머무는 시간이 길다.

메뉴 막대 아이콘을 누르면 맨 위에 지금 캐릭터 이름과 고른 지표의 사용률이 나오고, 그 아래에서 캐릭터, 말투, 지표를 바꾸거나 앱을 끌 수 있다.

## 설치

[Releases](../../releases)에서 `Dallyeora-버전.dmg`를 받아 열고, 창 안의 `Dallyeora.app`을 옆에 있는 Applications 폴더로 끌어다 놓으면 설치가 끝난다. macOS 14 이상이면 Apple Silicon 맥과 Intel 맥 모두에서 돌아간다.

Apple 공증을 받지 않은 앱이라 처음 열 때 macOS가 막는다. 앱을 우클릭해서 "열기"를 누르면 되고, macOS 15 이상에서 그래도 안 열리면 시스템 설정의 개인정보 보호 및 보안 화면 아래쪽에 뜨는 "그래도 열기" 버튼을 누르면 된다. 한 번 열고 나면 다음부터는 그냥 실행된다.

Dock에는 아이콘이 나오지 않고 메뉴 막대에만 나타나니, 끌 때는 메뉴 막대 아이콘을 눌러 "종료"를 고르거나 메뉴를 연 상태에서 ⌘Q를 누르면 된다.

## 어떻게 움직이나

2초마다 macOS 커널에서 CPU tick 수와 메모리 페이지 통계를 함께 읽는다. CPU 사용률은 직전 tick 값과의 차이로 계산하고, 두 값을 늘 같이 재 두기 때문에 지표를 바꾸면 바로 반영된다. 아이콘은 사용률이 0%일 때 0.2초에 한 번, 100%일 때 0.03초에 한 번 다시 그리고, 그 사이는 사용률에 비례해서 간격이 줄어든다. 아이콘은 단색 템플릿 이미지로 그려서 다크 모드와 라이트 모드에서 색을 시스템이 알아서 맞춘다.

캐릭터는 이미지 파일 없이 전부 Core Graphics로 선과 도형을 그려서 만들었다. 메뉴 막대 폭은 고른 캐릭터의 문구 중 가장 긴 것에 맞춰 고정해 두어서 단계가 바뀔 때마다 옆 아이콘들이 밀리지 않게 했는데, 노치가 있는 맥북에서 메뉴 막대가 꽉 차 앱이 가려지는 일을 막으려고 문구 폭은 최대 150pt까지만 쓰고 넘치는 부분은 말줄임표로 자른다.

## 직접 빌드하기

Swift 6 툴체인이 필요하고, Intel과 Apple Silicon을 함께 지원하는 앱으로 묶으려면 Command Line Tools만으로는 안 되고 Xcode가 설치되어 있어야 한다.

```bash
swift test                  # 단위 테스트
swift run Dallyeora         # 빌드하고 바로 실행
scripts/make-app.sh 0.3.0   # dist/에 Dallyeora.app과 dmg를 만든다
```

`swift run`으로 띄운 앱과 `.app`으로 띄운 앱은 설정이 따로 저장되기 때문에, 한쪽에서 바꾼 캐릭터가 다른 쪽에는 반영되지 않는다.

코드는 AppKit 없이 테스트할 수 있는 로직과 그림을 `Sources/DallyeoraCore`에, 메뉴 막대 UI를 `Sources/Dallyeora`에 나눠 두었다. 캐릭터를 하나 더 넣고 싶으면 `Sources/DallyeoraCore/Mascots/`에 `Mascot` 프로토콜을 구현한 파일을 만들고 `Mascots.all`에 등록하면 메뉴에 바로 나타난다. 그림 좌표계는 28×18이고 y축이 아래로 향한다. 처음 세운 설계는 [docs/spec.md](docs/spec.md)에 있다.

## 한계

사용률이 0%여도 0.2초마다 아이콘을 다시 그리기 때문에 아무것도 하지 않는 앱보다는 전력을 조금 더 쓴다. 타이머에 여유 시간(tolerance)을 줘서 시스템이 깨어나는 횟수를 묶을 수 있게 했지만, 화면이 꺼져 있을 때 그리기를 멈추는 처리는 아직 없다. 로그인할 때 자동으로 켜는 기능도 없어서, 필요하면 시스템 설정의 일반 > 로그인 항목에 직접 추가해야 한다.
